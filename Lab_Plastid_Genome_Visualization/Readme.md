## OGDRAW Settings
The circular plastid genome map was generated using OGDRAW with the following parameters:
* **Map Mode:** Standard circular map
* **Sequence Source:** Plastid
* **Inverted Repeat (IR) Detection:** Automatic detection
* **Selected Options:** Display GC content graph, show direction of transcription, display full legend, and label intron-containing genes with an asterisk (`*`)
* **Output Format:** PNG

## Main Structural Features Observed
The complete chloroplast genome of *Lavandula angustifolia* exhibits a total length of 153,448 bp with a standard circular quadripartite architecture. It consists of a Large Single-Copy (LSC) region hosting primary photosynthetic and transcription complexes (`psaA`, `psbA`, `rpo` genes), a Small Single-Copy (SSC) region harboring the NADH dehydrogenase gene family (`ndh` genes), and two identical Inverted Repeat regions (IRa and IRb). The inverted repeat regions contain duplicated copies of ribosomal RNA operons (`rrn16`, `rrn23`), which are reflected as distinct high GC content peaks in the inner GC content graph.
